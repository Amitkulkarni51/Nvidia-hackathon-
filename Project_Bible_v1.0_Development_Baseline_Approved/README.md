# Hackathon AI Project Template

This repository template is designed for a 4-person hackathon team using multiple AI coding tools.

## Core Idea

```text
Research
  ↓
Project Bible
  ↓
Approved Requirements + Architecture + Contracts
  ↓
Role-Specific AI Prompts
  ↓
AI Coding Tools
  ↓
Feature Branches
  ↓
Pull Requests
  ↓
Integration
  ↓
Final Product
```

## Golden Rules

- The team decides WHAT to build.
- The Project Bible documents WHAT.
- Role prompts tell each AI what it is responsible for.
- AI decides HOW to implement within the approved architecture.
- GitHub is the shared source of truth for documentation and code.
- No AI silently changes another member's module.
- Cross-module changes require review.
- Product/architecture decisions are human-approved.

## First Setup

1. Fill in `docs/01_problem_statement.md`.
2. Complete and approve research.
3. Define users and product vision.
4. Freeze MVP requirements.
5. Define architecture.
6. Define database schema.
7. Define API contracts.
8. Define design system.
9. Record important decisions.
10. Generate/update role-specific prompts.
11. Create feature branches.
12. Start parallel implementation.
13. Integrate early and repeatedly.

## Important

The role prompt files are templates. Before use, fill in the exact approved task and make sure the relevant Project Bible documents are current.
